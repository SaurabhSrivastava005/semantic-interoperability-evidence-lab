# Business Context and Ontology Capabilities for AI
These are related vendor capabilities, not interchangeable implementations of one standard. All profiles are source-based drafts; implementation outcomes remain not-evaluated.

| Offering | Documented focus | Main implementation question |
|---|---|---|
| [Genie Ontology](../catalogue/records/databricks-genie-ontology.md) | Curated and inferred context for Genie | Which definition is selected, and why? |
| [Palantir Ontology](../catalogue/records/palantir-ontology.md) | Objects, relationships and operational actions | How do governed meaning and authorised actions connect? |
| [Fabric IQ ontology](../catalogue/records/microsoft-fabric-iq-ontology.md) | Entities, data bindings and metric context | Which source and calculation remain authoritative? |
| [Snowflake Semantic Views / Cortex Analyst](../catalogue/records/snowflake-semantic-views-cortex.md) | Business semantics for analytical SQL generation | Does the generated query preserve intended meaning? |
| [Google Knowledge Catalog](../catalogue/records/google-knowledge-catalog-context.md) | Metadata and business-context retrieval | What context reaches the consuming application? |

## Read the labels carefully
Genie Ontology is Public Preview and Fabric IQ ontology is Preview in the inspected documentation. No blanket availability or maturity label is assigned to the other offerings. Check the actual feature, deployment, region and release before relying on it.

A product capability is not the organisation-specific ontology or graph created with it. A shared category does not establish equivalent action support, inference, openness, portability or standards conformance.
