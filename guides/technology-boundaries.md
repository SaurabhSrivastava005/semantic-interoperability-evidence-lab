# Languages, Specifications and Graph Platforms
Keep enabling technology separate from the business meanings or data built with it.

| Technology | Category | Official source inspected |
|---|---|---|
| RDF 1.1 | Graph representation framework | [Concepts and abstract syntax](https://www.w3.org/TR/rdf11-concepts/) |
| OWL 2 | Ontology language | [Document overview](https://www.w3.org/TR/owl2-overview/) |
| SPARQL 1.1 | Graph query language and related specifications | [Overview](https://www.w3.org/TR/sparql11-overview/) |
| DTDL | Digital-twin modelling language | [Profile](../catalogue/records/dtdl.md) |
| Neo4j | Graph database platform | [Profile](../catalogue/records/neo4j-platform.md) |

The W3C references are named editions, not claims about the newest available versions. RDF defines a graph data model, but does not supply an industry's business ontology. OWL supports ontology expression; SPARQL supports querying. None is a ready-made business knowledge graph.

Checked 2026-10-19. Source types: standards-body and vendor documentation. Full rights, runtime compatibility and business outcomes were not assessed. The existing grouped W3C catalogue entry is a family pointer, not a single normative release.
