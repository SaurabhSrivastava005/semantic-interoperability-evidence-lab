## Scope, dependencies and evidence
Brick defines building metadata using an RDF class hierarchy and relationships connecting equipment and subsystems. A building-specific graph is a separate artifact that instantiates the ontology.

The inspected repository uses semantic versioning and distinguishes nightly development builds from released versions. Select the ontology release, required imported vocabularies and validation tools for each case.
