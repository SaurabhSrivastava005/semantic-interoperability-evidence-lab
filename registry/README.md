# Standards Catalogue
Browse [the YAML index](registry-index.yaml) or [industry guides](../docs/industries/README.md).

The index is a starter discovery catalogue. Existing entries have not been accepted as independently verified recommendations. Their versions and reuse terms require review before adoption. Earlier unsourced maturity and conformance labels have been removed.

Create individual standard profiles in this directory using [the template](../templates/standard.md). Reuse the catalogue ID and link the profile from the entry. Record official sources, specific versions, jurisdiction, access conditions, related use cases, cases and exceptions.

A public specification is not necessarily open-source software. A conformity tool being available does not mean SIEL has tested conformance.
