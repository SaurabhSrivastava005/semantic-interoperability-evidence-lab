## Scope, dependencies and evidence
Power BI semantic models provide reporting-ready data models. Microsoft documents different model/storage arrangements, including imported and DirectQuery data.

This is a product modelling capability, not one universal sector model. A specific authored model needs its own measures, relationships, security context, refresh requirements and evaluation record.

The documentation page is public; this check does not establish rights to customer models or a Power BI service entitlement.

Source: [official semantic-model documentation](https://learn.microsoft.com/en-us/power-bi/connect-data/service-datasets-understand), Semantic model types. No specific model, report accuracy, cross-tool equivalence or production performance was assessed.
