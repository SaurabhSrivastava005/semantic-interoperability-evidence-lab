# 0001: Curated standards and implementation evidence hub
Date: 2026-10-19  
Status: Proposed in this change; owner direction recorded  
Reviewer: Pending pull-request review

## Context
The repository described a software platform and benchmark programme. The repository owner clarified that the goal is one place to find standards, industry exceptions, successful implementation cases and approaches that did not meet requirements.

## Decision
Focus current work on curated discovery and evidence records. Remove platform delivery commitments from current guidance. Preserve earlier proposals in an explicitly non-current archive.

## Alternatives
Continue the platform programme; maintain a link directory only; curate linked standards, use cases, implementation cases and exceptions. The third option addresses the stated user need while retaining evidence and context.

## Consequences
No software installation or benchmark implementation is required to contribute. Claims need sources and editorial review. Empty collections remain visible until credible cases are contributed. Historical proposals are not evidence of implementation.

## Reconsideration
Revisit access tooling if content volume and user feedback justify a searchable documentation site. A broader product requires a separate scope decision.
