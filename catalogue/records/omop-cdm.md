# OMOP Common Data Model

[Catalogue metadata](../index.yaml) · [Evidence policy](../../guides/evidence-policy.md)

## Purpose and versions
OHDSI's CDM structures observational health data and standard vocabularies for research. The official site inspected identifies v5.5 as current and separately documents v5.4. This does not identify the versions used in historical cases.

## Availability and licensing
- Documentation: the site states CC BY-SA 4.0 unless otherwise specified.
- Software: the CommonDataModel R package DESCRIPTION declares Apache License 2.0.
- Vocabulary distributions and constituent terminologies require separate checks; do not extend the software licence to them.
- Review status: source statements checked, not a comprehensive rights clearance.
