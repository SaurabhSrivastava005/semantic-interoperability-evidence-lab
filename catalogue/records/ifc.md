## Purpose and version boundary
IFC describes building information exchange. The [GeoBIM evidence](../../evidence/implementations/construction-geobim-ifc.md) concerns IFC2x3 and IFC4 software workflows. It does not evaluate current IFC4.3 products.

## Licensing check
The buildingSMART IFC4.x development repository's ifc4.3-main licence file states CC BY-ND 4.0 and explicitly identifies the repository as development material. The official IFC4.3 release page also exposes a CC BY-ND notice in indexed text, but direct retrieval failed during this check.

- Verification: partial; do not substitute a development branch for a released normative specification.
- Reuse: link to sources; do not relicense copied material as SIEL content.
- Gaps: check the exact release notice, third-party exclusions and any separately obtained ISO publication before redistribution.
- SIEL has not determined rights for every IFC artifact.
