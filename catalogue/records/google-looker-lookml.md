# Google Looker semantic modelling with LookML

[Catalogue metadata](../index.yaml) · [Evidence policy](../../guides/evidence-policy.md)

## Purpose and category
LookML defines dimensions, calculations, aggregates and data relationships used by Looker to generate SQL. It is a modelling language and product capability, not a prebuilt industry common data model.

Models and views are authored in LookML projects. A particular customer's model must be assessed separately from the language.

## Dependencies and rights
The documented execution path uses Looker and an underlying database. Record the product release, database dialect, joins and metric definitions for a real case. Cross-tool portability has not been tested here.
