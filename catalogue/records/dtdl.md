# Digital Twins Definition Language (DTDL)

[Catalogue metadata](../index.yaml) · [Evidence policy](../../guides/evidence-policy.md)

## Scope, dependencies and evidence
DTDL is a language for describing IoT digital-twin interfaces and models. It is not itself a prebuilt industry ontology or a populated graph.

The official README lists versions and differing service support. A model's language version must match the intended runtime; shared JSON-LD ancestry does not prove interchangeable execution.

The inspected [content licence](https://github.com/Azure/opendigitaltwins-dtdl/blob/master/LICENSE) states CC BY 4.0. Code notices, customer model rights and service entitlements need separate checks.
