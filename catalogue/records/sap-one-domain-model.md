# SAP One Domain Model

[Catalogue metadata](../index.yaml) · [Evidence policy](../../guides/evidence-policy.md)

## Purpose
SAP describes One Domain Model as a common model for exchange and reuse between SAP business applications and their ecosystem. Its Master Data Integration documentation links data exchange to supported ODM integration models.

## Source-check limits
These descriptions were available in indexed official Help Portal text. Direct retrieval returned no readable page body. Scope verification is therefore partial; no current normative ODM release was established.

The number 2211 appears in a Commerce integration documentation context. It must not be used as the version of ODM itself.

## Licensing and dependencies
Check the relevant SAP applications, integration service, supported integration model and version. Runtime entitlements, schema reuse rights, extension limits and redistribution terms remain unverified. Public documentation is not an open licence for the model.
