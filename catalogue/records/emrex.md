# EMREX and the ELMO exchange format

[Catalogue metadata](../index.yaml) · [Evidence policy](../../guides/evidence-policy.md)

## Purpose
EMREX supports exchange of learner results. ELMO is its XML exchange representation, based on EuroLMAI. Treat the network, schema and underlying CEN standards as distinct assets.

## Version and licence check
The ELMO repository view inspected uses v2.1.2. Its README directs implementers to releases and warns that master may contain unreleased changes.

At tag v2.1.2 both MIT LICENSE and EUPL-1.2 LICENSE.txt exist. This check does not resolve which licence applies to each file or whether a choice is intended. Confirm applicability with the steward before copying, modifying or redistributing. Do not describe all EMREX components or underlying CEN material under one licence.
