# Financial Industry Business Ontology (FIBO)

[Catalogue metadata](../index.yaml) · [Evidence policy](../../guides/evidence-policy.md)

## Scope, dependencies and evidence
FIBO describes financial concepts and relationships using OWL. It is an ontology, not a populated customer graph or a transaction system.

The official site describes EDM Council sponsorship and OMG standardisation. Neither establishes a regulatory mandate for a particular user. Pin ontology modules and release versions before assessing mappings or reasoning behaviour.

The repository README identifies an MIT code licence. Do not extend that label automatically to every ontology artifact; inspect its licence metadata and notices.

Sources: [official overview](https://spec.edmcouncil.org/fibo/), About FIBO; [repository](https://github.com/edmcouncil/fibo), README and release links. Source type: steward documentation. No bounded implementation outcome or maintenance cost was assessed.
