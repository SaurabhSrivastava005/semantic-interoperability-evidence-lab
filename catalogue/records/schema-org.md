## Scope, dependencies and evidence
Schema.org provides a cross-domain vocabulary. It is not the same thing as a populated enterprise knowledge graph or a local business metric model.

The inspected Terms of Service state that the sponsors' copyrights in the schema are licensed under Creative Commons Attribution-ShareAlike 3.0. Check the actual vocabulary release and any third-party notices for a planned reuse.

Source: [official terms](https://schema.org/docs/terms.html), Scope of Terms of Services; License. This replaces the catalogue's vague licence description for this asset, but does not establish an implementation outcome.

Record local meaning, version and use-case requirements before treating a shared property name as equivalent across systems.
