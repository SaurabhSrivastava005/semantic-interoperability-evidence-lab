# Microsoft Common Data Model

[Catalogue metadata](../index.yaml) · [Evidence policy](../../guides/evidence-policy.md)

## Purpose and access
Microsoft describes extensible entities, attributes, relationships and semantic metadata for business and analytical applications. Public schemas and SDK code are available in the CDM repository. Industry schemas are separately versioned; this record does not establish a single current model release.

## Licensing and dependencies
The repository's Legal Notices assign CC BY 4.0 to documentation and other content, and MIT to code. Product subscriptions, trademarks and third-party rights remain separate. A public schema does not grant access to Microsoft services or prove compatibility with every product.

For SDK-backed use, pin the SDK and schema dependencies. See the [Schema Store maintenance notice](../../evidence/exceptions/microsoft-cdm-schema-store.md). No runtime deployment was tested.
