# Cube semantic data models

## Scope, dependencies and evidence
Cube documents models using cubes, measures, dimensions and views. Views expose selected parts of the model to consumers.

This entry describes a modelling system. Each authored business model needs separate evidence for calculation correctness, joins, access controls, caching and consumer compatibility.

The public guide does not establish a blanket licence or runtime entitlement for every Cube offering or authored model. Those rights were not assessed in this batch.

Source: [official data-modelling guide](https://docs.cube.dev/docs/data-modeling/overview), Creating a Cube, measures and views. No measured implementation result or cross-tool semantic equivalence was evaluated.
