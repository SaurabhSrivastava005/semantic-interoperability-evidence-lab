# GeoBIM benchmark: uneven IFC software interoperability

## Scope and reported outcome
Noardo and colleagues tested IFC software behaviour using benchmark datasets and volunteer submissions. They document inconsistent interpretation and export across geometry, semantics and georeferencing.

- Provisional outcome: partially-successful; consistent interchange was not achieved across the tested combinations.
- Source type: primary research, Transactions in GIS; author preprint inspected.
- Versions: IFC2x3 and IFC4 dataset tests; not an evaluation of current IFC4.3 tooling.
- Observation: GeoBIM benchmark 2019; preprint v2 dated 7 January 2021.
- Cost and production reliability: not established.
- SIEL reproduction: none.

## Limits
Participant expertise and possible dataset issues are acknowledged. The finding applies to the tested versions and workflows, not every IFC product.
