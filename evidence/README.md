# Implementation Evidence and Exceptions

| Collection | What belongs here |
|---|---|
| [Implementation cases](implementations/README.md) | A named project, intended outcome, reported result and supporting source |
| [Exceptions and limitations](exceptions/README.md) | A reported mismatch, tradeoff or explicitly documented boundary |

Read finding types before interpreting a result. A vendor maintenance notice or licensing restriction is not an observed implementation failure. Case outcomes apply only to their stated scope and versions.

All current records are draft unless their metadata states otherwise. Use the [evidence policy](../guides/evidence-policy.md) for outcome and source labels. Follow catalogue links to inspect the underlying model or product.
