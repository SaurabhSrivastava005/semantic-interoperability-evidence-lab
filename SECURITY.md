# Security and Publication Safety
This repository curates standards references and implementation experience. Do not submit credentials, personal data, confidential schemas or sensitive organisational information.

Report exploitable repository vulnerabilities privately through GitHub security advisories when available. Use public issues for ordinary sourced content corrections without exposing private information.

Treat external links and contributed files as untrusted. AI-assisted summaries require human source verification. Do not execute code from linked case studies merely to assess a publication. Link to official sources and avoid uploading restricted standards or private correspondence.
