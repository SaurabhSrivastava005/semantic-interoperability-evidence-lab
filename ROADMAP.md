# Roadmap

## Current foundation

- [x] Curated-hub charter, editorial governance and evidence rules.
- [x] One metadata index and canonical record per catalogue ID.
- [x] Eight industry guides, bounded use-case guides and sourced case drafts.
- [x] Vendor, ontology, analytical, graph and AI-context discovery coverage.
- [x] Separate implementation limitations from documented product and licensing boundaries.
- [x] Generated browse views and local content-integrity checks.

## Next: improve evidence quality

- [ ] Review entries listed in the [current verification backlog](guides/verification-status.md).
- [ ] Recruit domain reviewers and accept the first independently reviewed records.
- [ ] Confirm exact releases, reuse rights and product dependencies where unresolved.
- [ ] Obtain full-method review for abstract-only cases.
- [ ] Collect bounded implementation cases for industries currently without evidence.
- [ ] Record maintenance effort, local extensions and unsuccessful or unresolved outcomes where sources support them.

## Maintain discovery coverage

- [ ] Triage uncatalogued leads before adding more categories.
- [ ] Update stale records when standards, products or source claims change.
- [ ] Collect user feedback on whether navigation helps a selection decision.
- [ ] Consider a searchable documentation site when content volume and demand justify it.

No software platform, mapping workbench, universal model or certification service is committed. Current counts are generated in the verification report rather than maintained in the roadmap.
